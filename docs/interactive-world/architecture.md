# Архитектура

```
клиент                                          сервер
──────                                          ──────
input E ─► interaction-manager ─► interact ───► game.handleInteract ─► interactive-state ─► SQLite (interactive_props)
                    │                                                        │
                    └─► mechSync.request ─► mech_set ─► mechanisms (двери)   └─► ball-physics (30 Гц)
carry-system ◄── prop_snapshot / prop_state ◄────────────────────────────────┤
ball-renderer ◄── ball_snapshot / ball_event ◄── physicsTick (снимки 10 Гц) ──┘
```

## Принципы

- **Сервер — источник истины.** Клиент ничего не решает о мячах и предметах: он отправляет намерение (`interact`) и показывает то, что прислал сервер.
- **Статика отдельно от подвижного.** Рамы дверей и корпуса остаются в слитой геометрии префабов; створки, дверцы, ящики, мячи и предметы — отдельные Mesh с общими геометриями и материалами (`sharedGeometry`).
- **Один цикл отрисовки.** Объекты не создают `requestAnimationFrame`; их `update(dt)` вызывает цикл сцены.
- **Чанки.** Mesh создаётся только если чанк под объектом загружен (`world.heightAt(x, z) !== null`); при выгрузке освобождается. Кеш 10 % считается как раньше — предметы и мячи в него не добавляют геометрию.
- **Существующее не ломаем.** Двери используют `mech_set` / `mech_state` вместе с воротами и лестницей; приоритеты у NPC и входов сохранены.

## Выбор цели для E

`pickInteraction` объединяет `pickCityInteraction` (вход, двери, ворота, NPC) и `pickWorldInteraction` (мяч, предмет, «поставить»):

1. побеждает ближайшая цель; предмет и мяч штрафуются за взгляд «мимо» (до ×1.5 за спиной);
2. цель за стеной (`segmentBlocked` по коллайдерам выше 0,6 м) недоступна;
3. «Поставить» имеет виртуальную дистанцию 1,4 м: вплотную к двери или NPC они важнее;
4. дребезг 220 мс; при UI-блокировке и открытых диалогах E не обрабатывается.

В учебной пожарной части свой локальный выбор цели (`interaction-target.js`), мебель добавлена туда кандидатами `furniture`.

## Серверные модули

| Модуль | Роль |
|---|---|
| `server/mechanisms/index.js` | Состояние дверей/ворот, проверка дальности, авто-закрытие (`sweep`) |
| `server/world/ball-physics.js` | Чистая физика мячей (без сети), тестируется отдельно |
| `server/world/interactive-state.js` | Предметы, владение, постановка, сохранение, мячи, рассылка |
| `server/world/placement.js` | `checkProp`, `staticObstacles` для предметов и мячей |
| `server/net/game.js` | `handleInteract`, `physicsTick`, снимки при входе, возврат предмета при выходе |
