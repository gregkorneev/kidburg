# Передача

## Состояние

Всё реализовано локально и не закоммичено (по условию задачи). Новые и изменённые файлы перечислены в `git status`; ничего не удалялось и не перезаписывалось из чужого. Для публикации нужны обычные шаги проекта: `npm run verify`, малые коммиты «область: что сделано», Wiki.

## Известные ограничения

- Музыкальная школа, радиостанция и мэрия: двери только анимируются, интерьеров нет.
- Закрытые стены зданий сплошные: открытая дверь не пропускает игрока.
- Состояние дверей хранится в памяти сервера (после перезапуска все закрыты).
- Предмет в руках не сохраняется в базе: после перезапуска возвращается на последнюю безопасную точку.
- Шкафы и ящики пожарной части локальны для страницы станции и не синхронизируются между игроками.
- Предмет в руках показан перед персонажем; камера «из-за спины» частично закрывает его телом.
- Визуальная проверка в браузерной панели шла при ~1 кадре/с; реальные FPS на целевых машинах не измерялись.
- Подвижные части в Control Center — только просмотр (`/api/admin/world/interactive`), редактирования нет.
