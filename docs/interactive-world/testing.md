# Тестирование

## Автоматические

```bash
npm test               # 611 тестов (до работы было 559)
npm run build
npm run verify
npm run check:offline
```

Новые файлы:

| Файл | Что проверяет |
|---|---|
| `server/world/ball-physics.test.js` | гравитация, отскоки, трение, стены, ворота, столкновения мячей, возврат, NaN |
| `tests/ws-interactive.test.js` | снимки при входе, взять/поставить, гонка двух игроков, руки заняты, границы постановки, отключение, перезапуск, футбол двух игроков, безопасность, поздний вход, двери (дальность, авто-закрытие) |
| `tests/interactive-world.test.js` | стартовые точки, `checkProp`, согласованность дверей, резерв мест, админский просмотр |
| `client/engine/mechanisms/door.test.js` | шарниры, состояния, разворот, `applyRemote`, dispose |
| `client/engine/mechanisms/furniture.test.js` | дверца наружу, независимые ящики, план мебели |
| `client/engine/interactions/interactions.test.js` | выбор цели, стены, дребезг, вход через дверь, экстраполяция мяча, рендерер, carry-system, `leaves:false` |

Все серверные тесты используют временные базы (`tempDb`).

## Ручная проверка в браузере

1. Запустить сервер с `DB_PATH` во временной папке; в двух вкладках (sessionStorage у каждой своя) войти разными именами с кодом комнаты.
2. `?debug=1` открывает `window.__cityDebug` (`carry`, `balls`, `interactions`) и `window.__fire` в пожарной части (`teleport(x, z)`, `showState`, `setCamera`).
3. Проверить: двери (E у пекарни, открытие створок), мяч (E рядом, второй игрок видит то же движение), предметы (взять / поставить, состояние видно с обеих вкладок), шкафы и ящики в `/firefighter-preview.html`.

Скриншоты: `docs/interactive-world/screenshots/`.

Замечание: встроенная панель браузера рисует около 1 кадра/с и в скрытом состоянии не запускает `requestAnimationFrame`, поэтому анимации надёжно проверяются при показанной панели и по численному состоянию (`object.progress`).
