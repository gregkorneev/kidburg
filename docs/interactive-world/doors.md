# Двери

Шесть дверей: `door-city-hall`, `door-fire`, `door-bakery`, `door-florist`, `door-music-school`, `door-radio` (описаны в `shared/doors.js`: здание, подпись, размеры проёма, цвета, `href` перехода).

## Устройство

- Рама и стена — статика префаба (`k.door(..., { leaves: false })`).
- `createDoor` (`client/engine/mechanisms/door.js`) строит две створки на независимых шарнирах у внешних кромок проёма. Угол раскрытия 1,75 рад наружу, ease-in-out, 0,9 с. Ручки и стёкла — часть створки.
- Состояния `closed → opening → open → closing`; разворот посреди движения идёт с текущего угла без скачка.
- Интерфейс совпадает с воротами: `applyRemote`, `open/close/toggle`, `wantsOpen`, `isOpen`, `progress`, `label` — поэтому `mechanism-sync.js` синхронизирует двери без изменений.

## Сервер

Двери — записи `type: 'door'` в `shared/mechanisms.js` (радиус 4,2 м, `autoCloseS: 12`). Игрок должен быть рядом (проверка `radius + запас`). Открытая дверь закрывается сама через 12 с (`mechanisms.sweep()` раз в секунду). Состояние хранится в памяти сервера и восстанавливается у вошедших позже по `mech_snapshot` с `progress`.

## Вход в станцию

E у двери: менеджер просит сервер открыть дверь, ждёт `isOpen` (или 3 с), затем вызывает прежний переход на страницу станции. Если игрок дальше радиуса двери — прежнее поведение (переход сразу). Пекарня получила вход `BAKERY_ENTRANCE` в `city-entrance.js`.

## Ограничения

- У музыкальной школы, радиостанции и мэрии нет страниц интерьера: дверь только открывается/закрывается, подсказка «Открыть дверь»/«Закрыть дверь». Фальшивых интерьеров нет.
- Здания сплошные: открытая дверь не создаёт проход, коллизий у створок нет (`blocking: false`).

## Как добавить дверь

1. Добавьте запись в `DOOR_SPECS` (`shared/doors.js`) и в таблицу `shared/mechanisms.js`.
2. В `k.door(...)` префаба передайте `leaves: false`.
3. В `client/engine/prefabs.js` оберните `decorate` префаба в `withDoors(base, ['door-…'])` (`city-mechanisms.js`).
4. Для станции со страницей задайте `href` в спецификации и вход в `CITY_ENTRANCES`.
5. Тест `tests/interactive-world.test.js` проверит согласованность здания, механизма и точки двери.
