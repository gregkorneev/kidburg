# Animated World — состояние и проверка

## Реализация

Реализация опубликована в `main`.

- Городская пожарная часть имеет проёмы под гаражные ворота и оболочечные коллизии. Секции ворот открываются и закрываются с обратимым направлением; закрытые ворота блокируют проход, открытые освобождают его.
- У учебной пожарной машины анимируются лестница и два маячка; колёса вращаются при смещении модели. Антенна радиостанции меняет направление, маячок на мачте мигает.
- Система ветра `client/engine/art/wind.js` управляет растениями, в том числе цветами флориста и сегментированной травой пожарной части. Материалы теней используют соответствующую деформацию. Разные экземпляры имеют разные фазы движения.
- Тестомес пекарни запускается при переходе к `ingredients_ready` и останавливается; порядок и правила задания не изменены.
- Ворота и лестница синхронизируются между клиентами: сервер передаёт цель и текущий прогресс, в том числе при позднем подключении. После выгрузки и повторной загрузки чанка клиент восстанавливает известное состояние механизма. Состояние сервера хранится в памяти и сбрасывается при его перезапуске.
- Доступны уровни качества Low, Medium и High. На Low теневые карты отключены; на Medium и High применяются настройки теней соответствующего уровня.

## Автоматические проверки

На коммите `aae3d35` выполнены `npm test` и `npm run verify`: по 584 теста без ошибок; `verify` также проверил `/health`. Выполнены `npm run build`, `npm run check:offline` и `git diff --check`. При том запуске `verify` мир в отдельной рабочей копии ещё не был сгенерирован; затем штатная `npm run world:build` создала индекс и 144 чанка.

Дополнительная временная проверка кода для ворот и лестницы подтвердила повторную команду с той же целью, разворот, частичный прогресс и повторную привязку. Она не заменяет браузерную приёмку.

## Ручная браузерная приёмка

По сообщению пользователя проверены два игрока в одной временной комнате, синхронизация ворот и лестницы, открытие, закрытие, разворот, позднее подключение и восстановление состояния. Проверены блокировка закрытыми городскими воротами и проход через открытые.

Пользователь также подтвердил работу маячков и антенны, запуск и остановку тестомеса на этапе `ingredients_ready`, пожарную часть, радиостанцию, пекарню и флориста, подсказки E, входы и коллизии. Проверены Low / Medium / High, анимация растений и теней, различие фаз растений и выгрузка с повторной загрузкой чанков. Визуальная проверка вращения колёс отдельно не подтверждена.
