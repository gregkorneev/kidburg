# Control Center

Вкладка «Агенты» (`/admin/`, пароль `ADMIN_PASSWORD`, по умолчанию только с компьютера сервера).

## Что изменилось

- `server/admin/routes.js`: `stationPlacement(agentId)` берёт размещение из реестра станций (для Маруси — прежнее, из `world.npcs`). Строка агента содержит `placement.passableWithoutAi`.
- `GET /api/admin/agents` возвращает дополнительно `services` (`serviceRows()`): ИИ-сервисы, не являющиеся собеседниками. Сейчас один — `radio_editor` со статусом Ollama и режимом `ollama` или `offline_fallback`.
- UI: `client/admin/agents-ui.js`, `components/Agents.jsx` — блок «ИИ-сервисы» над списком персон.

## Состояние API и прежняя проверка интерфейса

2026-11-01 `GET /api/admin/agents` проверен через тестовое приложение с локальной Ollama и временной конфигурацией: ответ `200`, состояние `ready`, модель `qwen3.5:2b`, `radio_editor.mode: ollama`; четыре NPC (три станционных наставника и Маруся) возвращены как размещённые и доступные без ИИ. При недоступном loopback-порту API вернул `ollama.state: unavailable`, `radio_editor.mode: offline_fallback`, сохранив HTTP 200.

Визуальный вид панели ранее проверялся в браузере, но повторить его после последних изменений не удалось: локальный браузер отключён в Work settings.
