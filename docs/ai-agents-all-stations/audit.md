## Причины устройства решения

- Станции — отдельные страницы со своими координатами, поэтому прежняя проверка `TALK_DISTANCE` по мировой позиции для них невозможна.
- Клиенту нельзя доверять `stationId`, позицию, этап и контекст: сервер сам хранит сессию станции и состояние задания.
- Память и очередь используют существующие `agent_memory` и `reply()` (два слота, очередь из восьми). Сейчас ответы трёх станционных наставников буферизуются целиком до проверки guard-шаблонов; клиент не получает токены по мере генерации.
- Радио не должно превращаться в чат-NPC.
