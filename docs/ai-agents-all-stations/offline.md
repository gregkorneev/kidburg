# Офлайн и работа без Ollama

- Новых внешних URL, CDN, шрифтов и аналитики нет; `npm run check:offline` проходит. Данные не уходят в интернет: Ollama — только loopback.
- **Без Ollama** разговор получает `agent_error` «Локальная модель недоступна (Ollama не запущена?)» (проверено в браузере), панель остаётся рабочей, кнопки действий и все задания проходятся. Control Center при этом показывает состояние Ollama.
- **Без сессии станции** (игрок открыл страницу станции напрямую или сервер недоступен) `link.ready` ложно: E работает как раньше, станция полностью локальная, разговора нет.
- **Радио без Ollama** использует прежний локальный учебный сценарий.
- Прогресс, набранный без сервера, остаётся локальным (`diverged`) и позже не переносится.
- Кеш мира (лимит 10%) не затронут: станции не добавляют объектов в чанки.
