# CARRIERIUM Control Center

Панель администратора «Города профессий». Работает внутри обычного сервера игры: отдельного порта, процесса и
внешних сервисов нет. Всё локально и офлайн.

## Запуск

```bash
ADMIN_PASSWORD='не-короче-8-символов' npm start
```

Панель открывается по адресу `http://localhost:3000/admin/` (порт — переменная `PORT`). Для разработки интерфейса:
`npm run dev` (Vite) + сервер игры отдельно.

| Переменная | Назначение |
|---|---|
| `ADMIN_PASSWORD` | Пароль администратора, **не короче 8 символов**. Не задан или короче — панель закрыта (`503 admin_disabled`). В репозиторий и клиентский код не попадает. |
| `ADMIN_ALLOW_REMOTE=1` | Разрешить вход с других компьютеров локальной сети. По умолчанию — только `localhost`. |
| `TELEMETRY_INTERVAL_MS` | Как часто клиенты присылают FPS/ping (по умолчанию 3000, предел 1000–30000). |
| `DB_PATH` | Путь к базе SQLite (по умолчанию `data/city.db`). Для проверок используйте временную базу. |

## Разделы панели

* **Обзор** — игроки, средний/минимальный FPS, средний/максимальный ping, активные сессии, чанки у клиентов,
  активные ИИ-агенты, динамические объекты, состояние Ollama, время работы. Нет данных — «Нет данных», не ноль.
* **Клиенты** — таблица сессий (имя, страница, FPS, ping, графика, чанки, состояние, последний сигнал),
  сортировка, фильтры, график FPS/ping по истории выбранной сессии.
* **Мир** — 2D-карта мира, библиотека разрешённых объектов, создание, перенос, поворот, масштаб, параметры,
  удаление, сброс динамического слоя. Проверка размещения выполняется сервером.
* **Агенты** — редактор настроек ИИ-агентов поверх базовой персоны, проверка на настоящей модели, сброс.
* **Журнал** — кто и что менял (мир, агенты, вход), откат последнего изменения мира.

## Данные

Новые таблицы SQLite создаются безопасной миграцией (`CREATE TABLE IF NOT EXISTS`), существующие данные не трогаются:
`world_objects`, `world_meta`, `agent_settings`, `admin_audit_log`.
