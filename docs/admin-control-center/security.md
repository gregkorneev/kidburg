# Безопасность Control Center

## Вход

* Пароль только из переменной окружения `ADMIN_PASSWORD` (≥ 8 символов). Если её нет — панель отвечает `503 admin_disabled`,
  войти нельзя ни при каких условиях.
* Пароль сравнивается через HMAC-SHA256 и `timingSafeEqual` (постоянное время).
* Ограничение попыток: 5 неверных паролей за 5 минут с одного адреса → `429 too_many`; пока блокировка действует, даже верный пароль не принимается.
* Сессия администратора независима от игровых токенов: игровой токен не открывает ни одного маршрута `/api/admin/*`,
  а сессия админа не даёт игровых прав.
* Сессии хранятся в памяти сервера (хэш токена SHA-256); перезапуск сервера завершает все сессии.

## Cookie и CSRF

* Cookie `carrierium_admin`: `HttpOnly`, `SameSite=Strict`, `Path=/`, `Max-Age=28800` (8 часов). `Secure` не ставится, потому
  что сервер работает по HTTP в локальной сети; по HTTPS-прокси флаг нужно включать на прокси.
* Изменяющие запросы требуют заголовок `X-CSRF-Token` (значение выдаётся при входе и в `status`) **и** `Origin` того же хоста.
  Иначе `403 bad_csrf` / `403 bad_origin`.
* Лимит изменяющих запросов: 40 за 10 секунд на сессию.

## Доступ по сети

* По умолчанию панель доступна только с самого компьютера-сервера (loopback и собственные адреса машины; `Origin` тоже
  должен быть локальным). Остальные получают `403 admin_remote_disabled`.
* `ADMIN_ALLOW_REMOTE=1` — осознанное разрешение для локальной сети. Пароль остаётся обязательным.

## Что не хранится и не передаётся

* Пароль, токены, cookie, CSRF и заголовки авторизации не пишутся в журнал (`redact()` вырезает такие ключи) и в логи.
* В клиентском JavaScript панели нет секретов; CSRF-токен живёт в памяти страницы, не в `localStorage`.
* Никаких внешних адресов: ни CDN, ни шрифтов, ни аналитики (проверяется `npm run check:offline`).

## Ограничения мутаций

* Тип объекта мира — только из фиксированного списка `shared/world-objects.js`; путей к файлам и кода клиент не принимает.
* Все координаты и параметры проверяются на сервере. Текст таблички очищается от управляющих символов и разметки и
  выводится как `textContent`.
* Настройки агентов проходят схему и фильтр явных попыток отменить правила игры; правила системы всегда идут первыми в промпте.
* Лимиты: 150 динамических объектов, 30 на чанк, размер тела запросов ограничен, телеметрия — 2 КБ на отчёт.
