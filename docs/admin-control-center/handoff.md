# Передача: Control Center

Состояние на 2026-11-01. Работа локальная; коммитов, push и записи в Wiki нет.

## Что готово

* Админ-панель `/admin/` (Preact, `client/admin/`), API `/api/admin/*`, SSE-поток, отдельная авторизация (`ADMIN_PASSWORD`).
* Телеметрия FPS/ping на всех страницах игры (город, пожарная часть, цветочная лавка, пекарня), клиентская часть — `client/engine/telemetry.js`.
* Динамический слой мира: SQLite, проверки размещения на сервере, синхронизация сообщениями `dyn_*`, откат, журнал, лимит кеша 10% сохранён.
* Настройки ИИ-агентов поверх базовой персоны без перезапуска; проверка на настоящей модели; сброс.
* Таблицы `world_objects`, `world_meta`, `agent_settings`, `admin_audit_log` (миграция `IF NOT EXISTS`).
* Документы (`README`, `architecture`, `security`, `telemetry`, `world-editor`, `agents`, `testing`) и скриншоты.

## Известные ограничения

* `npm run check:offline` падает на `client/hud/minimap.js:15` (SVG-пространство имён), не из-за этой работы.
* Телеметрия и сессии админа живут в памяти сервера: после перезапуска история пуста, админ входит заново.
* Карта админки — SVG (≈ 1 700 статических маркеров одним путём); масштабирование не мерилось на слабых машинах.
* Логотип в шапке — исходный PNG 1,4 МБ; стоит сделать уменьшенную копию.
* Валидация размещения (`POST /world/validate`) считается изменяющим запросом (лимит 40 за 10 с), поэтому интерфейс ограничивает её до одного запроса в 350 мс.
* После отката ревизии более ранних записей журнала перезаписываются (`rebaseAuditRev`), поэтому номера версий в старых записях меняются.
* Мелочи интерфейса: после «Применить» остаётся подпись «Есть несохранённые правки», хотя изменения применены.
* `scripts/start.mjs` не читает `DB_PATH` (см. происшествие в [testing.md](testing.md)).
* Не добавлялись зависимости и не использовался Playwright.
