# Телеметрия клиентов

## Как собирается

Каждая страница игры — город, пожарная часть, цветочная лавка, пекарня — запускает `startTelemetry()`
(`client/engine/telemetry.js`). Раз в несколько секунд (интервал отдаёт сервер, по умолчанию 3 с) страница шлёт
`POST /api/telemetry` с токеном игрока (`Authorization: Bearer`, токен из `sessionStorage`):

```json
{ "sid": "s…", "loc": "city|firefighter|florist|bakery", "state": "active|paused|hidden",
  "quality": "low|medium|high", "fps": 60, "frameMs": 16.7, "ping": 4.2,
  "render": { "calls": 0, "triangles": 0, "geometries": 0, "textures": 0 }, "chunks": { "loaded": 9, "max": 14 } }
```

* `sid` — случайный идентификатор вкладки на время жизни страницы (не личность). Две вкладки одного игрока — две сессии.
* FPS — **среднее за окно** между отчётами (число кадров / время), а не мгновенное значение.
* `ping` — время ответа `GET /health` (тип `http`); для подключённых по WebSocket сервер дополнительно знает свой RTT.
* Скрытая вкладка → `state: hidden`, FPS не принимается; нет кадров при видимой вкладке → `paused`.
* При закрытии страницы отправляется `{ sid, bye: true }` с `keepalive`.
* Число чанков для города берётся у сервера (зеркало кеша), у остальных страниц — не указывается.

## Статусы

| Статус | Когда |
|---|---|
| `online` | отчёты идут, вкладка активна |
| `inactive` | вкладка скрыта или рендеринг приостановлен (FPS «нет данных») |
| `offline` | `bye` или тишина дольше 3 интервалов; FPS/ping не показываются |

Отключённая сессия остаётся в списке 2 минуты, затем удаляется.

## Хранение и пределы

* Только в памяти сервера, в базу не пишется (после перезапуска история пуста — честно «нет данных»).
* История: 120 точек на сессию (≈ 6 минут при 3 с). Предел: 200 сессий всего, 8 на игрока.
* Отчёты чаще, чем раз в ~половину интервала, отклоняются (`too_fast`); чужой `sid` — `foreign_session`.
* Пороги подсветки: FPS < 30, ping > 150 мс.

## Проверка корректности

Парсер строгий: отрицательные, нечисловые и огромные значения → `400`, а не молчаливое «0». Юнит-тесты:
`tests/telemetry.test.js`, `client/engine/telemetry.test.js`.
