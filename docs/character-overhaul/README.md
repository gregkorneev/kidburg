# Character Overhaul 2.0 — локальный отчёт

Все изменения **локальные и не закоммичены** (`git status` — только изменённые и новые файлы, коммитов и push нет).
Система расширена, а не заменена: публичный API `client/engine/art/character.js` прежний
(`createCharacter`, `animateCharacter`, `setPersonEquipment`, `triggerGesture`, `setArmReach`, `armsLocked`…),
сетевой протокол, сервер, БД, координаты объектов и задачи не менялись. Внешних URL и новых зависимостей нет.

## Архитектура

`character.js` — фасад. Реализация разложена по модулям `client/engine/art/`:

| Файл | Ответственность |
|---|---|
| `character-appearance.js` | Справочники вариантов, `appearanceFromSeed(seed, color)`, `resolveAppearance` |
| `character-geometry.js` | Общие геометрии: торс, конечности (3 сегмента ног, 2 — рук), голова по форме лица, кисти, обувь, таз, уши/нос |
| `character-hair.js` | 13 причёсок: параметрическая оболочка черепа + пряди/пучки; верх прячется под каской/шапкой |
| `character-face.js` | Глаза, веки, брови, рот, щёки; 7 эмоций; моргание, взгляд, речь |
| `character-outfits.js` | Верхняя одежда (5 видов), обувь (3), аксессуары (5), перчатки, пожарный комплект, костюмы профессий |
| `character-animation.js` | Походка/бег, поворот, дыхание, жесты, речь, взгляд, поза переноса, `setArmReach` |
| `character.js` | Сборка, слои одежды `applyLayers`, качество, `reactToEvent`, `dispose` |

Иерархия: `root > body (покачивание, контакт с землёй) > lean (наклон, ось на уровне таза) > spine (скручивание) > torso / руки / голова / форма`.
Ноги и таз под `body`. Руки: плечо → локоть → кисть. Все геометрии и материалы общие (`userData.shared`),
`disposeCharacter` их не освобождает. Скелетов и внешних моделей нет — всё процедурное.

Слои одежды: повседневная → костюм профессии → пожарный комплект; решаются в одном месте (`applyLayers`).
Пожарный комплект и костюмы строятся лениво при первом включении.

## Внешность

Детерминированна по id: `appearanceFromSeed(id, serverColor)` на хеше, **без `Math.random`** (тест это проверяет).
Числовой цвет от сервера становится цветом одежды, остальное берётся из seed — один id выглядит одинаково на всех клиентах.

- Причёски (13): short, sidePart, bob, long, curly, wavy, spiky, messy, bun, updo, ponytail (только наставник), lowTail, sweep. Цвета: 8.
- Комплекции (3): standard, compact, broad. Формы лица (4): round, oval, wide, heart.
- Глаза: форма, размер, цвет; брови (стили), нос, рот, высота ушей.
- Одежда: tee, hoodie, jacket, sweater, shirt; цвет акцента; обувь: sneaker, boot, safety. Аксессуары: backpack, glasses, cap, headband, bag (~40% жителей).

## Эмоции

Семь: `neutral, happy, surprised, thinking, sad, focused, confused`. Лицо хранит числовые `cur/target` и сглаживает переход;
явная эмоция (`setExpression(person, name, {intensity, duration})`) важнее подразумеваемой жестом; временная эмоция возвращается к нейтральной.
Моргание — детерминированный PRNG на персонажа, взгляд и «осмотры» — от `look.seed`.

## Анимация

- Ходьба/бег: бедро → колено → стопа, контакт с землёй решается аналитически (`body.y`), перекат стопы, наклон корпуса на беге, скручивание плеч, крен на повороте.
- Покой: дыхание, перенос веса, микродвижения, у каждого свои «привычки» (`quirk` из seed).
- Жесты: `wave, nod, point, approve, think, surprise, lift`; поза переноса `setCarry`.
- Речь: огибающая фраз, слоги и биты → рот, голова, жестикуляция свободной руки; планшет у Маруси держится.
- Руки при `armsLocked` (шланг/хват манекена) не трогаются; `setArmReach` растягивает сегменты пропорционально.
- Без аллокаций в кадре; нечисловые входы кадра (`dt`, `t`, `speed`, `lookYaw`) отбрасываются (см. «Найденные проблемы»).

## Костюмы и экипировка

Пожарная форма (каска, куртка, сапоги, перчатки, полосы, наколенники) сохранена и работает поверх любой внешности;
каска прячет макушку причёски. Костюмы профессий: `baker, florist, musician, radio` (`setPersonCostume`), пожарная форма важнее костюма.

## Маруся

`scene.js`: явная внешность (seed 4107, овальное лицо, зелёные глаза, дуги-брови, сапоги), характер `personality {expression:'happy'}`.
`reactToEvent(npc, event)`: `greet`, `talk_start`, `task_success`, `task_complete`, `task_error`. Здоровается на подходе, смотрит на игрока, во время речи жестикулирует.

## Мультиплеер

Сетевой протокол не менялся. Внешность строится из id (и цвета сервера), поворот для крена считается из разности `ry` в снимках.
Качество передаётся в `createRemotePlayers({quality})`. Поза переноса игрока и экипировка — прежними путями.
**Эмоции и жесты не синхронизируются по сети** (нет полей протокола) — у удалённых игроков видны ходьба, бег, поворот, дыхание, моргание.

## Уровни качества

`low/medium/high` → `detail 0/1/2`: число сегментов геометрий, веки/нижние веки/щёки, мелкие детали, покачивание волос. `setCharacterQuality(level)` вызывается из `scene.js` и `chunks.js`.
Смена качества во время игры влияет на **новых** персонажей.

## Найденные проблемы

1. **`scene.js`, `animate()` вызывался без аргумента** (в HEAD тоже): `previousFrameTime = undefined` → следующий `delta = NaN` → `npc.rotation.y += NaN`,
   поворот Маруси необратимо портился. Исправлено значением по умолчанию `timestamp = performance.now()`.
2. Из-за этого же новая анимация (она хранит состояние) «отравлялась» NaN: `animateCharacter` теперь отбрасывает нечисловые `dt/t/speed/lookYaw`; регрессионный тест проверен (падает без защиты).
3. Инвертированные нормали у `LatheGeometry` (профиль снизу вверх) — исправлено в `unitLathe`.
4. Первая версия новой системы давала ~11k треугольников/персонаж; сегменты уменьшены (см. [performance.md](performance.md)).
5. Отладочный `spawnRemote` в `scene.js` через `updateRemotePlayers` сбрасывает экипировку (`addRemotePlayer(id)` с `equipped=false`) — поведение из HEAD, не менялось.

## Ограничения

- Эмоции и жесты не передаются по сети; уровень качества применяется к новым персонажам.
- Мешей на персонажа больше, чем было (36 против 22) при меньшем числе треугольников; слияние мешей рук/лица — возможная следующая оптимизация.
- Обувь «кроссовок» мягкая, на малых расстояниях напоминает тапок; фартук пекаря (плашки) чуть «парит» (z-смещение ~0.03 хотело бы уменьшить).
- Страница предпросмотра не входит в `vite build`; в рабочем дереве есть чужие неотслеживаемые файлы `* 2.js` (дубликаты, не мои, не трогал).
- Wiki не обновлялась (запрещено задачей); отчёт — в этой папке.
