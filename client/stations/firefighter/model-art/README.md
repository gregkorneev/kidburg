# Рабочая копия для художника

`firefighter-art.blend` — отдельная копия технической заготовки из `model-source/firefighter.blend`. Она не содержит новой художественной правки сетки и не является утверждённой моделью. Исходные `.blend`, `.glb` и скрипт генерации не менялись. Нового GLB для игры нет.

В `views/` сохранены ортографические изображения исходной формы: спереди, сбоку, сзади и крупный план лица. Один и тот же набор источников света использован для всех ракурсов; он создан только во время рендера и не записан в `.blend`. Скрипт `render_views.py` создаёт камеры и свет в памяти и не изменяет геометрию и файл модели.

Рабочая задача для 3D-моделлера: вручную переработать лицо и непрерывность его поверхности (щёки, подбородок, нос, глазницы и веки), силуэты причёски, плеч, рук, кистей, ног и обуви; затем проверить форму на тех же четырёх ракурсах. До утверждения внешности не начинать анимации и интеграцию в игру. Риг в техническом исходнике черновой и не подтверждён для деформации.

Blender 4.5.15 запускается в этой среде в фоновом режиме, но интерактивное окно при проверке не создалось из-за ошибки графического контекста EGL. Поэтому ручное моделирование здесь не выполнено и качество референса не достигнуто.
