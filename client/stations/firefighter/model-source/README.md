# Художественная заготовка пожарного

`firefighter.blend` — редактируемый исходник, `firefighter.glb` — локальный экспорт для `art-preview.html`, `firefighter.py` — воспроизводимый генератор этой заготовки. Модель создана для оценки и не утверждена для игры.

При установленном или переносимом Blender 4.5 перегенерация выполняется из корня репозитория:

```sh
blender --background --factory-startup --python client/stations/firefighter/model-source/firefighter.py -- "$(pwd)/client/stations/firefighter/model-source"
```

Запуск генератора перезапишет оба файла. Скелет и группы вершин черновые: веса жёсткие, сгибы и мимика не настроены, анимаций нет. Необходимы ручные скульптинг лица, волосы, одежда, ретопология, исправление весов и тестирование деформаций. Для просмотра запустите `npx vite --config vite.config.js` и откройте `/stations/firefighter/art-preview.html` на показанном сервером адресе; открытие HTML как `file://` не поддерживает загрузку модулей и модели.
