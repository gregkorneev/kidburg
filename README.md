# Город профессий

Браузерная многопользовательская 3D-игра для знакомства с профессиями. Игрок исследует город, общается с NPC-наставниками и выполняет учебные задания. Проект рассчитан на запуск в локальной сети и автономную демонстрацию на одном компьютере.

> Проект находится в разработке. Описание актуальной архитектуры и ограничений — в [контексте проекта](docs/PROJECT_CONTEXT.md), технический план — в [спецификации тимлида](docs/lead-spec.md).

## Возможности проекта

- 3D-клиент на Three.js с интерфейсом на Preact.
- Сервер Node.js с HTTP API, WebSocket и SQLite.
- Многопользовательская синхронизация игроков по локальной сети.
- Подгрузка мира чанками и ограничение клиентского кеша.
- Центральная площадь с пожарной частью: у двери показывается вход по `E`, из локации возврат в город по `L`.
- Обучающая смена пожарного с серверным сохранением прогресса и диалогом с Марусей через локальную ИИ-модель.
- Локальные ресурсы: игра не зависит от CDN и внешних сервисов во время запуска.

## Требования

- Node.js версии 22 или новее.
- npm.
- Git.

## Запуск

```bash
git clone https://github.com/gregkorneev/kidburg.git
cd kidburg
npm ci
npm run setup
npm run world:build
npm run build
npm start
```

`npm run setup` подключает Git hooks проекта. `npm run world:build` создаёт файлы города, а `npm run build` собирает страницы игры. Оба шага повторяйте после соответствующих изменений исходников.

Сервер печатает адреса для открытия игры и код комнаты. На компьютере-сервере откройте `http://localhost:3000`; на остальных устройствах той же локальной сети — адрес `в сети`, напечатанный сервером. Участник вводит своё имя и код комнаты. На компьютере-сервере код подставляется автоматически. Если серверный компьютер должен отвечать Марусе, задайте `OLLAMA_MODEL` с именем модели, установленной в локальной Ollama, например:

```bash
OLLAMA_MODEL=Qwen3:latest npm start
```

Без настроенной локальной модели сервер и игра запускаются, но ИИ-диалог NPC недоступен.

## Как попасть в пожарную часть

1. Войдите в игру на центральной площади.
2. Подойдите к двери пожарной части. У западной пешеходной дорожки появляется подсказка **E — Войти в пожарную часть**.
3. Нажмите `E`, чтобы открыть локацию. Прогресс смены хранится на сервере и связан с вошедшим игроком.
4. Нажмите `L` в пожарной локации, чтобы вернуться на центральную площадь.

Пожарная локация открывается по адресу `http://<адрес-сервера>:3000/firefighter-preview.html`. Для перехода между страницами используется та же браузерная сессия.

Для разработки доступны отдельные процессы сервера и Vite:

```bash
npm run dev
```

## Проверка

```bash
npm run verify
```

Дополнительные команды:

| Команда | Назначение |
| --- | --- |
| `npm test` | Запустить тесты на встроенном `node:test` |
| `npm run build` | Собрать клиент для production |
| `npm run check:offline` | Проверить использование внешних адресов в клиенте |
| `npm run world:fixtures` | Создать фикстуры мира |
| `npm run world:build` | Построить файлы мира из исходных данных |
| `npm run bots` | Запустить клиентских ботов для разработки |
| `npm run agent-chat` | Запустить консольный интерфейс агента |

## Структура репозитория

| Путь | Содержание |
| --- | --- |
| `client/` | Браузерный 3D-клиент и UI |
| `server/` | HTTP/WebSocket сервер, база данных, задачи и агенты |
| `shared/` | Общие константы, протокол и форматы данных |
| `content/` | Игровой контент |
| `assets/` | Локальные ресурсы проекта |
| `tools/` | Инструменты разработки и построения мира |
| `tests/` | Автоматические проверки |
| `docs/` | Контекст проекта, техническая спецификация и заметки по контрактам |

## Ограничения разработки

- JavaScript с ES-модулями; TypeScript не используется.
- Не добавляйте внешние URL, CDN, веб-шрифты или аналитику в игровой клиент.
- Клиент использует относительные HTTP-адреса и WebSocket текущего хоста.
- Не меняйте `shared/` и API-контракты без согласования.
- Не добавляйте зависимости без согласования.
- Перед коммитом запускайте `npm run verify`.

Подробные правила работы и распределение каталогов приведены в [`AGENTS.md`](AGENTS.md).
